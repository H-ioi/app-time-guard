# 04 防绕过与安全需求

管控产品一旦能被孩子轻易绕过，就失去价值。本章采用**威胁模型驱动**：先列出孩子可能的手段，再给出对应防御措施，并定义安全等级。

## 4.1 威胁模型（孩子可能的绕过手段）

| 编号 | 绕过手段 | 难度 | 后果 |
| --- | --- | --- | --- |
| T1 | 关闭 App（划掉后台任务） | 低 | 管控服务停止，规则失效 |
| T2 | 卸载管控 App | 低 | 直接摆脱管控 |
| T3 | 关闭无障碍服务 / 使用情况访问 | 中 | 无法拦截应用、无法统计 |
| T4 | 修改系统时间（回拨日期） | 中 | 配额重置，延长使用时间 |
| T5 | 重启设备（绕过内存态锁定） | 中 | 锁定状态丢失 |
| T6 | 进入应用详情页强制停止 | 中 | 服务被杀 |
| T7 | 进入开发者模式 / 用 ADB 卸载 | 高 | 高级绕过 |
| T8 | 安装新 App 绕过白名单 | 中 | 绕过应用范围限制 |
| T9 | 换机/切换用户（多用户模式） | 高 | 完全脱离管控 |
| T10 | 恢复出厂设置 | 高 | 清除全部管控 |
| T11 | 关闭通知权限（错过提醒） | 低 | 体验问题 |
| T12 | 用浏览器访问受限内容 | 中 | 绕过应用级限制 |
| T13 | 应用分身（华为等系统支持，复制受限 App） | 中 | 分身 App 绕过白名单/黑名单 |
| T14 | 投屏后息屏（投屏到电视/多屏协同，平板息屏观看） | 低 | 屏幕关闭后系统判定应用"不在前台"，观看内容不消耗配额 |

## 4.2 防御措施

### 4.2.1 权限架构层（基础防线）

| 能力 | 用途 | 获得方式 |
| --- | --- | --- |
| 设备所有者 Device Owner | 防卸载、锁屏、禁用设置项、禁用多用户 | adb / 企业配置（引导时提供详细图文，仅平板等专用设备推荐；华为 HarmonyOS 可用 adb 激活，需关闭纯净模式并按系统提示输入验证口令） |
| 设备管理员 Device Admin | 锁屏、改锁屏密码（手机端降级方案） | 常规激活 |
| 无障碍服务 AccessibilityService | 拦截 App 启动、覆盖锁定界面、检测窗口变化 | 引导授权 |
| 使用情况访问 UsageStatsManager | 时长统计、App 识别 | 引导授权 |
| 通知使用权 NotificationListener | 检测/阻止孩子关闭关键通知、后台保活 | 引导授权 |

### 4.2.2 逐威胁防御对策

| 威胁 | 防御对策 |
| --- | --- |
| T1 划掉后台 | 服务常驻（前台服务 + 通知使用权 + 厂商保活引导）；被划掉后开机/解锁时自检恢复 |
| T2 卸载 | ① 设备所有者模式：彻底防卸载；② 非所有者模式：无障碍监控"卸载确认页"，拦截并提示家长 PIN；卸载后首次解锁发出强烈警告 |
| T3 关服务 | 无障碍被关闭时：通知使用权检测到系统"关闭无障碍"操作即拦截/告警；家长端红色警告 + 审计；孩子端显示"家长已收到通知" |
| T4 改时间 | ① 用单调时钟（SystemClock.elapsedRealtime，自开机递增、用户无法修改）作为配额结算基准，改系统时间无法重置配额；② 维护"系统时间-单调时间"偏移基准，检测到偏移突变判定篡改；③ 篡改期间按"最保守"结算并上报家长 + 审计。纯本地实现，无网络依赖 |
| T5 重启 | 锁定状态持久化（本地数据库）；重启后开机自启恢复锁定；若处于锁定态则继续锁定直到到点 |
| T6 强停 | 设备所有者可禁止；普通模式：无障碍监控"强制停止"页面并拦截提示 |
| T7 ADB/开发者 | 设备所有者模式禁用开发者选项；引导家长关闭 USB 调试 |
| T8 新装 App | 应用安装监听：新装 App 默认按"白名单模式"判为禁止，家长需手动确认加入白名单 |
| T13 应用分身 | 识别并默认禁止分身包名（华为分身应用为独立包名，与主应用一并列入管控）；引导家长在华为「设置 > 应用 > 应用分身」中关闭该功能 |
| T14 投屏息屏 | ① 显示监听：DisplayManager 检测外部显示/无线投屏连接（真机验证华为 Cast+ 触发情况）；② 投屏期间息屏仍按"使用中"结算（见 02 章 2.2.4 默认策略）；③ 兜底启发式：息屏 + 音频播放中判定为活跃；④ 家长可选"投屏即锁定"严格策略 |
| T9 多用户/换机 | 设备所有者模式禁用多用户（单设备使用，无账号体系） |
| T10 恢复出厂 | 无法绝对防止（系统层面）；设备所有者模式可减少意外触发；文档中向家长说明 |
| T11 通知关闭 | 通知使用权监听通知权限变化，发现被关即告警 |
| T12 浏览器 | 浏览器可被列入黑名单/分类限制；白名单模式默认全禁 |

### 4.2.3 家长区保护
- 进入家长模式：PIN（4~6 位，防猜测：连续 5 次错误锁 30 秒，可配置）+ 可选生物识别；
- 家长模式界面在失去焦点（切后台）后自动退出并回到孩子模式；
- 家长模式操作全部留痕（审计日志）；
- 忘记 PIN：纯本地无账号，兜底方案为"卸载重装（清除数据）"后重新设置，设置向导中明确说明。

### 4.2.4 锁定界面的抗破解
- 锁定界面使用无障碍叠加层 + 全屏 Activity 双重实现（防返回键、Home 键后仍锁定）；
- 锁定期间屏蔽：返回键、Home 键（需设备所有者）、最近任务、通知下拉（可配置）；
- 锁定界面自身禁止被截图/录屏（FLAG_SECURE）；
- 冷却倒计时以本地持久化 + 可信时间源双校验，防"杀进程绕过倒计时"。

## 4.3 安全等级与推荐配置

| 等级 | 适用 | 配置 |
| --- | --- | --- |
| 标准（默认） | 大多数家庭（手机） | 无障碍 + 使用统计 + 设备管理员；防 T1~T6、T8、T11、T12 |
| 严格 | 专用平板/学习机 | 标准 + 设备所有者：防卸载、禁多用户、禁开发者模式、禁 USB 调试 |
| 宽松 | 年龄较大/自觉孩子 | 仅提醒 + 统计，不强制锁定（"监督模式"） |

> 默认引导家长进入"标准"等级；平板用户提供"严格"等级升级引导。

## 4.4 数据与隐私安全

| 项 | 要求 |
| --- | --- |
| 数据存储 | 使用统计、规则、日志仅存本地（纯离线）；敏感项（PIN）加密存储（Android Keystore） |
| 数据权限 | 仅家长模式可见统计与日志；孩子模式不可见 |
| 数据导出 | CSV 导出到本地，导出时明确提示内容范围 |
| 最小权限 | 仅申请实现功能所必需的权限，权限用途均有文案说明 |
| 合规 | 纯本地离线：无账号、无网络传输、无云存储，不涉及个人信息外发，App 不申请网络权限 |

## 4.5 安全测试要点（开发验收参考）
- 模拟 T1~T12 全部绕过路径，验证防御生效或至少"告警 + 留痕"；
- 锁定界面返回/Home/最近任务/下拉通知各 10 次连续尝试均不可退出；
- 时间篡改前后配额结算正确性（向前/向后各测）；
- 卸载、强停、关无障碍后，家长端告警可达性（通知被禁时降级为开机横幅）。

## 4.6 HarmonyOS NEXT 版（纯血鸿蒙）威胁差异

NEXT 权限体系与 Android 不同，威胁模型存在差异：

| 威胁 | NEXT 版差异 |
| --- | --- |
| T2 卸载 | 普通应用无法防卸载；依赖华为系统"家长守护/健康使用手机"，或引导家长开启应用锁 |
| T3 关服务/无障碍 | AccessibilityExtensionAbility 关闭同样需监测告警；真机验证 NEXT 通知监测可达性 |
| T7 ADB/开发者 | 普通应用无法禁用开发者模式；引导家长关闭 USB 调试；NEXT 无"纯净模式侧载"概念（仅应用市场安装） |
| T9 多用户 | NEXT 不支持多用户切换，天然免疫 |
| T13 应用分身 | NEXT 已取消应用分身，威胁不存在（Android 版专属） |
| T14 投屏息屏 | NEXT 支持投屏/多屏协同，同样存在"息屏投屏观看"绕过；检测能力需真机验证（显示监听 API 开放度），不可达部分引导家长使用华为系统"健康使用手机"的应用限额（限额覆盖前台使用，投屏形态需家长观察） |
| 全局锁定/防 Home | NEXT 普通应用无法实现系统级拦截，强管控依赖华为系统方案（见 05 章 5.9.4） |

NEXT 版安全等级：仅"标准级"（提醒 + 统计 + 本 App 内管控）；"严格级"（防卸载、全局锁屏）在 NEXT 上由华为系统级方案承担，本 App 负责引导。
