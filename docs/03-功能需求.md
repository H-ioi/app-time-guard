# 03 功能需求

本文档定义产品各端的功能清单与交互要求，分为：家长端（配置与干预）、孩子端（日常使用体验）、统计报告、通知提醒。

## 3.1 功能总览

```
App（单 App 双模式）
├── 首次启动引导（设置向导）
├── 家长模式（PIN/生物识别进入）
│   ├── 首页（今日概览 + 快捷操作）
│   ├── 规则配置（机制 A1~C4 全部入口 + 模板）
│   ├── 应用管理（白名单/黑名单/分类）
│   ├── 统计报告（日报/周报）
│   ├── 干预操作（锁定/暂停/奖励时长/临时放宽）
│   ├── 系统设置（PIN、重置时刻、防绕过开关等）
│   └── 审计日志
└── 孩子模式（默认）
    ├── 状态展示（剩余时间/休息倒计时/当前规则）
    ├── 锁定界面（缓冲提醒/冷却倒计时/就寝时钟）
    └── 请求帮助（呼叫家长）
```

## 3.2 首次启动引导（设置向导）

**目标**：家长 3 分钟完成配置，不靠说明书。

| 步骤 | 内容 |
| --- | --- |
| 1. 角色声明 | 选择"我是家长"，设置家长 PIN（4~6 位）+ 可选生物识别 |
| 2. 权限授予 | 引导开启：无障碍服务、使用情况访问、通知使用权、设备管理员/设备所有者（各权限配图文说明） |
| 3. 华为专项（检测到华为设备时显示） | 引导将 App 加入「应用启动管理」手动管理、关闭电池优化限制、关闭应用分身；侧载安装时引导关闭纯净模式 |
| 4. 选择模板 | 选孩子年龄段模板（3-6 / 7-12 / 13-15 / 自定义） |
| 5. 微调规则 | 展示模板摘要，可立即微调（时长、时间段、白名单） |
| 6. 完成 | 进入孩子模式；提示"如需更改，长按时钟图标进入家长模式" |

> 权限未完全授予时，给出"哪些能力暂不可用"的明确提示，并允许"稍后完成"。

## 3.3 家长端功能

### 3.3.1 首页（今日概览）
- 今日已用时长 / 剩余时长（环形进度）；
- 当前生效规则摘要（"19:00-21:00 可用 · 剩余 45 分钟 · 单次 30 分钟"）；
- 快捷操作：立即锁定、暂停管控、+15 分钟；
- 孩子当前状态（使用中 / 休息中 / 锁定中）。

### 3.3.2 规则配置
- **模板中心**：一键套用预设模板，套用后可微调；
- **每日总时长**：A1 配置（时长、重置时刻、到期动作、冷却恢复）；
- **单次与间隔**：A2/A3 配置（连续上限、休息时长、用停交替 X/Y、首段豁免）；
- **可用时间段**：B1 配置（每天 1~4 段、按星期区分）；
- **周计划**：B3 配置（每日独立，复制到其他天）；
- **假期模式**：B4 配置（多方案管理、假期起止日期）；
- **就寝模式**：B2 配置（起止时间、紧急应用、时钟显示）；
- **作业/专注模式**：C4 配置（时段 + 学习白名单）；
- **规则生效即时性**：保存即生效；冲突提示（如"与就寝模式重叠，将按就寝模式执行"）。

### 3.3.3 应用管理
- App 列表：全部已安装应用，显示图标、名称、分类、使用时长；
- 白名单管理：勾选允许项；支持按类别整批加入；
- 黑名单管理：勾选禁止项；提示与白名单互斥；
- 分类修正：手动调整单个 App 的类别；
- 系统例外：电话/紧急拨号/必要系统项开关；
- 隐藏敏感项：家长可勾选"App 列表对孩子隐藏"。

### 3.3.4 干预操作（全部留痕）
| 操作 | 行为 |
| --- | --- |
| 立即锁定 | 全屏锁定，需家长 PIN 解锁 |
| 暂停管控 | 选择时长（15/30/60/120 分钟/无限期），到期自动恢复 |
| +奖励时长 | +5/10/15/30/60 分钟，追加到当日配额 |
| 临时放宽 | 选 App + 时长，到期自动恢复 |

### 3.3.5 系统设置
- 家长 PIN 修改 / 生物识别开关；
- 配额重置时刻；
- 防绕过开关（见 04：时间可信源、防卸载提醒、无障碍守护）；
- 投屏处理策略（见 02 章 2.2.4）：投屏计为使用（默认）/ 投屏即锁定 / 允许投屏不计数，附"投屏可能识别不全"的如实说明；
- 华为专项引导（一键跳转：应用启动管理、电池优化、应用分身、纯净模式，附图文说明）；
- 通知偏好（提醒提前量、是否静默）；
- 数据导出（CSV，供家长留存）。

### 3.3.6 审计日志
- 记录：规则修改、锁定/解锁、奖励、临时放宽、绕过尝试（如检测到时间篡改）；
- 展示：按时间倒序，含操作类型与时间戳。

## 3.4 孩子端功能

### 3.4.1 状态常驻展示
- 桌面悬浮球 / 状态栏常驻图标：显示剩余可用时间或休息倒计时；
- 轻点展开小卡片：剩余时长、当前规则、距锁定时间；
- 样式友好（卡通/柔和配色），不吓唬孩子。

### 3.4.2 提醒与缓冲
- 剩余 10/5/1 分钟：顶部横幅提醒（可关闭声音）；
- 到期：全屏"时间到"提示 + 5 分钟缓冲倒计时（可配置为 0）；
- 缓冲期间显示"正在保存你的进度…"，孩子可正常退出当前 App。

### 3.4.3 冷却/休息界面
- 用停交替、冷却恢复期间显示全屏休息界面：
  - 大号休息倒计时（如"休息 12:34"）；
  - 温馨文案/小贴士（护眼提示、喝水提示）；
  - 休息结束后自动恢复；
- 就寝模式显示"晚安"时钟界面（大号时间、柔和夜间配色）。

### 3.4.4 拦截提示
- 被禁 App 启动时：全屏提示"这个应用需要爸爸/妈妈同意才能使用"；
- 提供"请求家长"按钮 → 同一设备上弹出本地通知提醒家长 → 家长进入家长模式后选择同意（临时放宽）或忽略。

### 3.4.5 规则变化提示
- 家长改规则后，孩子端显示轻提示（"规则已更新：今天还能用 90 分钟"）。

## 3.5 统计报告

### 3.5.1 日报（默认首页图表）
| 指标 | 说明 |
| --- | --- |
| 今日总使用时长 | 与配额对比（环形图） |
| 各时段使用分布 | 24 小时条形图（何时在用、何时锁定） |
| App 使用排行 | Top 5（时长 + 占比） |
| 解锁次数 | 今日/昨日对比 |
| 休息/冷却时长 | 用停交替产生的休息累计 |

### 3.5.2 周报 / 月报
- 每日时长趋势折线图（含配额线）；
- 平均每日使用时长、最长单日；
- App 周排行（识别"某游戏 5 小时/周"）；
- 深夜使用记录（22:00 后使用次数）；
- 违反提醒次数（如超时被拦截次数）。

### 3.5.3 导出与分享
- CSV / 长图导出（家长留档或与孩子复盘）。

## 3.6 通知提醒

| 通知类型 | 触发 | 展示位置 |
| --- | --- | --- |
| 即将到期 | 剩余 10/5/1 分钟 | 横幅（孩子端） |
| 已锁定 | 配额耗尽/时段结束 | 全屏界面 |
| 休息结束 | 冷却完成 | 横幅 + 解锁 |
| 孩子请求 | 孩子点击"请求家长" | 家长端本地通知（同一设备） |
| 绕过警告 | 检测到时间篡改/无障碍被关闭 | 家长端警告 + 审计日志 |
| 今日报告 | 每日 21:00 可选提醒 | 家长端本地通知 |

## 3.7 无障碍与易用性要求（对家长）
- 所有配置页面：默认值合理、提供示例文案（"比如：放学后 19:00-21:00"）；
- 关键操作不超过 3 步；模板一键套用；
- 支持浅色/深色主题；家长端大字号模式；
- 文案面向普通家长（无技术术语，如"无障碍服务"旁配"用于阻止打开被限制的应用"说明）。
