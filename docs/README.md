## 一句话定位

一款**家长可配置、孩子难绕过、界面够简单**的 Android 设备使用管控 App：灵活组合「时长配额、用停交替、时间段、应用白名单/黑名单」等机制，让孩子按规则使用电子产品，帮家长守护孩子的用眼与作息。
