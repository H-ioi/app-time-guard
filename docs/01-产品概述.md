# 01 产品概述

## 1.1 产品背景与痛点

孩子使用平板、手机已成为普遍现象，随之而来的是家长的普遍焦虑：

- **时长失控**：一玩就停不下来，说好的"玩一会儿"变成一两个小时；
- **频率失控**：频繁解锁、碎片化使用，眼睛和作息受影响；
- **内容失控**：孩子悄悄玩游戏、刷短视频、逛应用商店；
- **家长心软/疲惫**：靠口头管理难以坚持，家长不在身边时完全失控；
- **工具难用**：现有管控方案要么过于复杂（家长都学不会），要么容易被孩子绕过。

本产品通过**系统级、可配置、防绕过的使用规则**，把"管控"从家长的口头监督，变成设备自身的自动执行。

## 1.2 产品定位

> 一款家长可配置、孩子难绕过、界面够简单的 Android 设备使用管控 App。

- **自动执行**：规则由系统自动执行，无需家长时刻在场；
- **灵活组合**：多种控制机制可自由组合，适配不同家庭、不同年龄段；
- **简单上手**：内置「一键模板」，3 步完成配置；
- **可靠防绕过**：设备所有者 + 无障碍 + 使用统计三重能力，堵住常见绕过路径。

## 1.3 目标用户

| 角色 | 说明 | 核心诉求 |
| --- | --- | --- |
| 家长（监护人，主用户） | 配置规则、查看报告、干预管控 | 省心、灵活、防得住 |
| 孩子（受控对象） | 在规则内使用设备 | 规则透明、别太烦人、有商量余地 |

**目标年龄段（设备使用者）**：3~15 岁（不同年龄段默认模板不同）。
**典型家庭形态**：1 台平板 / 1 台手机，1~2 位家长共同管理。

## 1.4 支持设备与平台

| 平台 | 支持情况 | 说明 |
| --- | --- | --- |
| Android 平板 | Android 版目标设备 | Android 8.0+（API 26+），主流厂商设备 |
| Android 手机 | Android 版目标设备 | 同上 |
| 华为平板（HarmonyOS 2/3/4.x，兼容安卓） | Android 版目标设备 | 运行 Android 版 APK，专项适配见 05-技术实现方案 5.6 |
| 华为平板（HarmonyOS NEXT / 5.x，纯血鸿蒙） | **独立 HarmonyOS NEXT 版** | 不兼容 Android APK，需 ArkTS 原生开发；能力分级，见 05-技术实现方案 5.9 |

> **纯本地离线运行**：无需联网、无账号、无云端、无远程控制端。家长管控、规则执行、统计报告全部在单台设备上完成。App 不申请网络权限。
>
> **双版本策略**：同时开发 **Android 版**（Kotlin 原生，完整管控能力）与 **HarmonyOS NEXT 版**（ArkTS 原生，按系统开放能力分级实现）。两版共享：需求文档、UI 设计稿、交互规范、规则引擎逻辑设计；不共享：技术栈与系统管控实现。

## 1.5 核心使用场景

### 场景 A：日常管控（最常用）
家长在周一早上设置"工作日规则"：每天 19:00 后可用，总时长 90 分钟，每次连续使用不超过 30 分钟，且必须休息 30 分钟才能继续。孩子按规则使用，到点设备自动锁定。

### 场景 B：作业/专注时段
周末上午 9:00-11:30 开启"作业模式"：仅学习类 App 可用，其余全部禁用，屏幕用满 30 分钟强制休息 5 分钟。

### 场景 C：只给学习 App
家长开启"全禁用 + 白名单"：设备上只有"XX网课、XX词典"等 2~3 个 App 能打开，其余全部无法启动。

### 场景 D：突发干预
孩子看动画超时，家长在家长模式下点「立即锁定」；或孩子表现好，家长临时奖励「+15 分钟」。

### 场景 E：睡前守护
21:30 后进入就寝模式，设备完全锁定，直到次日 7:00 自动解除；晚间偷偷解锁的行为被记录并上报给家长。

### 场景 F：周计划差异
工作日执行"上学日模板"（1 小时 + 学习优先），周末执行"休息日模板"（2 小时 + 娱乐放宽），假期一键切换到"假期模板"。

## 1.6 产品价值

1. **对孩子**：规则清晰、有始有终，养成时间管理习惯；到点提醒 + 缓冲，避免"突然被掐断"的对抗感。
2. **对家长**：无需时刻盯着，规则自动执行；报告一目了然，发现使用问题；临时干预一键完成。
3. **对家庭**：减少因"玩手机"引发的争吵，把时间还给亲子互动。

## 1.7 角色与权限模型

产品采用**单 App 双模式**架构：

| 模式 | 进入方式 | 权限 |
| --- | --- | --- |
| 孩子模式（默认） | 开机即进入 | 只能使用被允许的 App，可查看"剩余时间/休息倒计时" |
| 家长模式 | 输入家长 PIN / 生物识别 | 配置规则、查看统计、干预管控、退出锁定 |

## 1.8 产品范围（全部为第一版必须实现）

### 第一版（必须）
- **双版本并行**：Android 版（完整管控能力）+ HarmonyOS NEXT 版（ArkTS 原生，能力分级，见 05 章 5.9）
- 全部核心控制机制：每日总时长、用停交替、可用时间段、应用白名单/黑名单、按应用限时、周计划、就寝模式
- 一键模板（上学日/周末/假期）
- 使用统计（每日/每周、App 排行、解锁次数）
- 到点提醒、缓冲倒计时、强制锁定界面
- 家长 PIN / 生物识别保护
- 防绕过基础能力（防卸载、防改时间、防关服务）

> 本产品**无远期规划**：不包含远程控制、多设备管理、云端账号、推送服务等任何联网能力，全部功能在单台设备上离线完成。

## 1.9 术语表

| 术语 | 含义 |
| --- | --- |
| 使用时长 | 设备处于"可用状态"的时长（屏幕解锁且处于允许使用状态） |
| 配额 | 某一时间窗口内允许使用的总时长上限 |
| 用停交替 | 使用 X 分钟后必须休息 Y 分钟才能继续使用 |
| 冷却期 | 配额耗尽后必须等待的时长（如用满后停 30 分钟） |
| 白名单 | 仅允许使用的 App 列表 |
| 黑名单 | 禁止使用的 App 列表 |
| 就寝模式 | 夜间强制锁定的时间窗口 |
| 家长 PIN | 进入家长模式或解除锁定所需的口令 |
| 锁定界面 | 孩子模式下到达限制时的全屏拦截界面 |
| 缓冲期 | 正式锁定前的提示倒计时（如剩余 5 分钟提醒） |
