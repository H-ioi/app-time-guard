# 使用守护（AppTime Guard）

家长管控孩子电子设备使用时长与频率的双版本 App（纯本地离线，无联网、无账号、无云端）。

## 版本

| 目录 | 版本 | 技术栈 | 适用设备 |
| --- | --- | --- | --- |
| `android/` | Android 版 | Kotlin + Jetpack Compose | Android 8.0+ 手机/平板；华为 HarmonyOS 2/3/4.x（兼容安卓） |
| `harmony/` | HarmonyOS NEXT 版 | ArkTS + ArkUI（Stage 模型） | HarmonyOS NEXT（5.x）平板/手机 |

## 核心能力

- **13 种控制机制**：每日总时长、用停交替（用 X 停 Y）、可用时间段、全禁用+白名单、黑名单、分类批量禁用、按应用限时、就寝模式、周计划、一键模板、家长锁定/暂停、奖励时长、临时放宽
- **规则引擎**：多规则"最严格优先"结算，状态机（可用/提醒/冷却/锁定）
- **防绕过**（Android 版完整实现）：时间篡改检测（单调时钟）、防卸载（设备管理员）、无障碍拦截、应用分身/投屏息屏防护、审计日志
- **统计报告**：日报（App 排行）、近 7 天趋势、审计日志、CSV 导出

## 能力差异（NEXT 系统限制）

| 能力 | Android 版 | HarmonyOS NEXT 版 |
| --- | --- | --- |
| 规则引擎/模板/报表/提醒 | ✅ | ✅ |
| 拦截受限应用 | ✅ 强拦截（无障碍） | ⚠️ 弱拦截（检测+通知引导） |
| 防卸载/全局锁屏 | ✅（设备管理员/设备所有者） | ❌ 引导华为「健康使用手机+家长守护」 |
| 时间篡改防护 | ✅ 单调时钟偏移检测 | ⚠️ best-effort |

详细需求见 `docs/`（README.md 索引）。

## 构建

- Android：Android Studio 打开 `android/`，`assembleDebug` 出 APK（详见 `android/README.md`）
- HarmonyOS NEXT：DevEco Studio 5.0+ 打开 `harmony/`，构建 HAP（详见 `harmony/README.md`）

## 使用流程

1. 首次启动进入 6 步（NEXT 3 步）设置向导：设家长 PIN → 授权（无障碍/使用统计/通知/设备管理员）→ 华为专项（保活/电池/分身）→ 选年龄模板 → 预览 → 完成
2. 孩子端大时钟显示今日剩余；长按时钟输 PIN 进入家长模式
3. 家长端：首页（状态+快速干预）、规则、应用、统计、设置（安全等级/投屏策略/重置时刻/导出）
